# Example - Alpaca Paper Trading

This sequence changes only a simulated account and is never run automatically:

1. Health
2. Alpaca Paper Connectivity
3. Account
4. Submit SPY Buy (small quantity)
5. Get Order and List Orders
6. List Positions and Get SPY Position
7. Close SPY Position
8. List Fills

Inspect each response before continuing. Alpaca credentials remain server-side.
